### Security Research & Tooling

**[Writeups](https://github.com/SleepTheGod/Writeups)**

**[pwner](https://github.com/SleepTheGod/pwner)**  
Automated LFI / arbitrary-file-read exploitation tool that identifies vulnerable `readfile()` (and equivalent) endpoints in PHP applications and exfiltrates sensitive data.

**[Wayback](https://github.com/SleepTheGod/Wayback)**  
Passive web reconnaissance tool supporting subdomain discovery via Certificate Transparency, archived URL discovery via the Internet Archive CDX API, and endpoint classification.

**[Wall-of-Shame](https://github.com/SleepTheGod/Wall-of-Shame)**  
Zero-dependency Bash script that monitors live SSH brute-force attempts from system journals and generates a dynamic web-based leaderboard.

**[DoxbinEndpointMapper](https://github.com/SleepTheGod/DoxbinEndpointMapper)**  
JavaScript utility for mapping endpoints of doxbin.com via browser console.

**[HTB-Endpoint-Mapper](https://github.com/SleepTheGod/HTB-Endpoint-Mapper)**  
Fetch-based script for mapping endpoints on Hack The Box labs.

**[Subenum](https://github.com/SleepTheGod/Subenum)**  
Production-focused passive subdomain enumeration using ProjectDiscovery Subfinder.

Proof-of-concept and patch research related to CVE-2026-9618.
